Introduction to Backend Web Development

Backend web development is the part of website development that works behind the scenes. It manages the server, application logic, databases and the processing of information received from users. When a user submits a form, logs in to a website or searches for information, the backend receives the request, processes it and sends a suitable response.

This subject introduces internet technologies and server-side programming. It explains how HTML forms communicate with PHP, how PHP handles data and how MySQL stores and retrieves information. HTML is used to create the structure of web pages, PHP is used for server-side processing and MySQL is used to manage data.

Course objective: To understand the basic concepts and techniques of server-side web programming and develop interactive, dynamic websites using HTML, PHP and MySQL.

1. Internet

The Internet is a worldwide network of interconnected computers and devices. It allows users to communicate, share information, access websites, send emails and use online services. Devices communicate through standard rules called protocols.

2. Internet Protocols

A protocol is a set of rules that defines how data is transmitted between devices over a network.

  • TCP (Transmission Control Protocol): Breaks data into packets and helps ensure that they reach the destination correctly and in order.
  • IP (Internet Protocol): Provides addressing and routing so packets can travel from a source device to a destination device.
  • HTTP (Hypertext Transfer Protocol): Transfers web pages and other resources between a browser and a web server.
  • HTTPS: Secure version of HTTP that encrypts communication using TLS.
  • DNS (Domain Name System): Converts human-readable domain names, such as example.com, into IP addresses.
  • SMTP (Simple Mail Transfer Protocol): Used to send email between mail clients and mail servers or between mail servers.

3. IP Addressing

An IP address is a numerical address assigned to a device on an IP network. It helps identify the device and route data to it.

  • IPv4: Uses 32 bits and is commonly written as four numbers separated by dots, for example 192.168.1.10.
  • IPv6: Uses 128 bits and is written in hexadecimal groups, for example 2001:db8::1.
  • Public IP: Used to identify a network on the public internet.
  • Private IP: Used inside local networks, such as a home or college network.

4. Domain Name System (DNS)

People find websites using domain names, while computers communicate using IP addresses. DNS works like an internet directory: it looks up the IP address associated with a domain name. A DNS lookup normally happens before a browser connects to a website.

HTML is the standard markup language used to structure web pages. Elements are written using tags. Common elements include headings, paragraphs, links, images, lists, tables and forms.

1. Introduction to PHP

PHP stands for PHP: Hypertext Preprocessor. It is a server-side scripting language used to create dynamic web pages. PHP code is executed on the server, and the resulting HTML is sent to the browser. PHP files generally use the .php extension.

2. Basic PHP Syntax

PHP code is written between <?php and ?> tags. Statements usually end with a semicolon.

<?php
echo "Hello, World!";
?>
Output: Hello, World!

3. Defining Variables and Constants

A variable stores a value that can change during program execution. In PHP, a variable begins with the $ sign. A constant stores a value that cannot be changed after it is defined.

<?php
$name = "Komal";
$age = 19;
define("COLLEGE", "My College");

echo $name;
echo "<br>";
echo $age;
echo "<br>";
echo COLLEGE;
?>
Output:
Komal
19
My College

1. HTML Forms

An HTML form is used to collect information from a user. It can contain text boxes, password fields, radio buttons, checkboxes, drop-down lists and submit buttons. The action attribute specifies the file that receives the form data, while the method attribute specifies how data is sent.

<form action="process.php" method="post">
  Name: <input type="text" name="name" required>
  <input type="submit" value="Submit">
</form>

2. Submitting Data to the Server Using GET

The GET method sends form data as part of the URL query string. It is suitable for searches and requests where the data does not need to be private. It should not be used for passwords or sensitive information.

<!-- search.html -->
<form action="get-result.php" method="get">
  Search: <input type="text" name="keyword">
  <input type="submit" value="Search">
</form>

<!-- get-result.php -->
<?php
if (isset($_GET["keyword"])) {
    $keyword = htmlspecialchars($_GET["keyword"]);
    echo "You searched for: " . $keyword;
}
?>
Example output: If the user enters PHP, the result page displays “You searched for: PHP”.

3. Submitting Data to the Server Using POST

The POST method sends form data in the HTTP request body rather than displaying it in the URL. It is commonly used for registration and login forms. HTTPS should be used to protect data in transit; POST by itself does not encrypt information.

<!-- post-form.html -->
<form action="post-result.php" method="post">
  Name: <input type="text" name="name" required>
  <input type="submit" value="Submit">
</form>

<!-- post-result.php -->
<?php
if (isset($_POST["name"])) {
    $name = htmlspecialchars($_POST["name"]);
    echo "Welcome, " . $name;
}
?>
Example output: Welcome, Aman

5. Student Registration Form

This example collects a student's name, email and course. The PHP page checks that the required values are present and displays them safely.

<!-- registration.html -->
<form action="register.php" method="post">
  Name: <input type="text" name="name" required><br>
  Email: <input type="email" name="email" required><br>
  Course: <input type="text" name="course" required><br>
  <input type="submit" value="Register">
</form>

<!-- register.php -->
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = trim($_POST["name"] ?? "");
    $email = trim($_POST["email"] ?? "");
    $course = trim($_POST["course"] ?? "");

    if ($name === "" || !filter_var($email, FILTER_VALIDATE_EMAIL)
        || $course === "") {
        echo "Please enter valid details.";
    } else {
        echo "Registration details received.<br>";
        echo "Name: " . htmlspecialchars($name) . "<br>";
        echo "Email: " . htmlspecialchars($email) . "<br>";
        echo "Course: " . htmlspecialchars($course);
    }
}
?>
Example output:
Registration details received.
Name: Aman
Email: aman@example.com
Course: BCA

6. Login Form Using Server-side Validation

A login form accepts a username and password. Server-side validation checks the submitted values on the server. This classroom example demonstrates validation only; a real login system must verify a password hash stored in a database and use secure session handling.

<!-- login.html -->
<form action="login.php" method="post">
  Username: <input type="text" name="username" required><br>
  Password: <input type="password" name="password" required><br>
  <input type="submit" value="Login">
</form>

<!-- login.php: simple demonstration only -->
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $username = trim($_POST["username"] ?? "");
    $password = $_POST["password"] ?? "";

    if ($username === "" || $password === "") {
        echo "Both fields are required.";
    } else {
        echo "Form data received. Add database-based password verification here.";
    }
}
?>
Example output: Form data received. Add database-based password verification here.

7. Server-side Validation

Server-side validation means checking submitted data using code running on the server before accepting or storing it. It is important because browser-side validation can be bypassed.

  • Check that required fields are not empty.
  • Validate email addresses using filter_var().
  • Check that numeric values are within an acceptable range.
  • Use htmlspecialchars() when displaying user-provided text in HTML.
  • Use prepared statements when inserting user data into a database.
<?php
$email = $_POST["email"] ?? "";
if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "Valid email address";
} else {
    echo "Invalid email address";
}
?>
Output: Displays “Valid email address” for a correctly formatted email, otherwise “Invalid email address”.

1. Introduction to MySQL

MySQL is a relational database management system (RDBMS). It stores information in tables made up of rows and columns. PHP can connect to MySQL to create databases, insert records, retrieve information and update or delete data.

2. Database Connectivity with PHP

PHP can connect to MySQL using MySQLi or PDO. The following example uses MySQLi. Replace the sample username and password with the database credentials configured on your computer.

<?php
$connection = new mysqli("localhost", "root", "", "college");

if ($connection->connect_error) {
    die("Connection failed: " . $connection->connect_error);
}
echo "Database connected successfully";
$connection->close();
?>
Output: Database connected successfully (when the server and database credentials are correct).

3. Database Creation

A database is a structured collection of related information. The CREATE DATABASE statement creates a new database.

CREATE DATABASE college;
Result: A database named college is created.

4. Creating Tables

A table stores data in rows and columns. Each column has a name and data type. A primary key uniquely identifies each row.

USE college;

CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(120) NOT NULL,
    course VARCHAR(50)
);
Result: A table named students is created with id, name, email and course columns.

5. Insertion of Data

The INSERT statement adds new records to a table. In PHP, prepared statements should be used to safely pass user input to SQL queries.

<?php
$conn = new mysqli("localhost", "root", "", "college");
if ($conn->connect_error) {
    die("Connection failed");
}

$name = "Aman";
$email = "aman@example.com";
$course = "BCA";

$stmt = $conn->prepare(
    "INSERT INTO students (name, email, course) VALUES (?, ?, ?)"
);
$stmt->bind_param("sss", $name, $email, $course);

if ($stmt->execute()) {
    echo "Record inserted successfully";
} else {
    echo "Error inserting record";
}
$stmt->close();
$conn->close();
?>
Output: Record inserted successfully (if the insertion succeeds).

6. Retrieval of Data

The SELECT statement retrieves records from a table. The following example displays all student records.

<?php
$conn = new mysqli("localhost", "root", "", "college");
if ($conn->connect_error) {
    die("Connection failed");
}

$result = $conn->query("SELECT id, name, email, course FROM students");

if ($result) {
    while ($row = $result->fetch_assoc()) {
        echo htmlspecialchars($row["name"]) . " - ";
        echo htmlspecialchars($row["email"]) . "<br>";
    }
}
$conn->close();
?>
Example output:
Aman - aman@example.com
(The actual output depends on the records stored in the database.)

8. Updating a Record Using PHP

<?php
$conn = new mysqli("localhost", "root", "", "college");
if ($conn->connect_error) {
    die("Connection failed");
}

$id = 1;
$newCourse = "BCA";

$stmt = $conn->prepare("UPDATE students SET course = ? WHERE id = ?");
$stmt->bind_param("si", $newCourse, $id);

if ($stmt->execute()) {
    echo "Record updated successfully";
}
$stmt->close();
$conn->close();
?>
Output: Record updated successfully (if the query executes successfully).

9. Deleting a Record Using PHP

<?php
$conn = new mysqli("localhost", "root", "", "college");
if ($conn->connect_error) {
    die("Connection failed");
}

$id = 1;
$stmt = $conn->prepare("DELETE FROM students WHERE id = ?");
$stmt->bind_param("i", $id);

if ($stmt->execute()) {
    echo "Record deleted successfully";
}
$stmt->close();
$conn->close();
?>
Output: Record deleted successfully (if a matching record is deleted).
