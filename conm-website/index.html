About the Subject

Computer Oriented Numerical Methods deals with computational techniques for solving mathematical problems that may be difficult to handle by direct analytical methods. It introduces error analysis, methods for finding roots of equations, techniques for solving systems of linear equations, interpolation, numerical integration and numerical solutions of ordinary differential equations.

The practical work uses C programs to demonstrate the logic of these methods. Each exercise includes a short problem description, source code and an illustrative sample run. Results may vary slightly with compiler settings and input values.
